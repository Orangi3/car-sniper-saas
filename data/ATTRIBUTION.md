# Data attribution

`zip_centroids.csv.gz` — US ZIP code centroid coordinates.
Coordinates from **GeoNames** (https://www.geonames.org/), licensed under
Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/),
extracted on 2026-10-28 from the MIT-licensed `zipcodes` Python package
v3.0.0 (https://github.com/seanpianka/Zipcodes), which compiles GeoNames
coordinates with USPS ZIP Locale Detail (public domain). Coordinates were
rounded to 4 decimal places; no other changes. Centroids are approximate:
a ZIP is an area, so distances are estimates.
